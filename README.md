# Lorenzo Fabres — Portfólio

Portfólio profissional desenvolvido para apresentar minha experiência, conhecimentos técnicos e projetos nas áreas de **Service Desk, Suporte de TI e Desenvolvimento Web**.

## Sobre o projeto

Este projeto consiste em um portfólio web responsivo desenvolvido para centralizar informações sobre minha trajetória profissional e principais conhecimentos técnicos.

O site apresenta minha experiência profissional, competências relacionadas a suporte técnico e ferramentas utilizadas em **Service Desk, suporte a sistemas, infraestrutura e desenvolvimento web**.
